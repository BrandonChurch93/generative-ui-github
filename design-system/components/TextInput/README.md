# TextInput

A labeled one-line field for a value the reader types, from a repo name inside a composed form to the landing page's paste-a-repo field at hero size.

- The composer picks TextInput only inside a Form, and only when the value cannot be offered as a list (a repo, a branch, a handle). Known choices go to Select or FilterChips. The hero size is never composed: it belongs to the landing shell.
- Schema: `label`, optional `placeholder` (an example of the format), optional `helper`, `kind` (`text` or `identifier`), `validate` (`repo`, `branch`, `handle` or `none`) and `required` (default true). The model chooses the wording of label, placeholder and helper, and the kind. The system decides size, color and validation, and writes every error sentence: each validator result maps to fixed wording, so the same mistake always reads the same.
- Label: `label` style, 13px, weight 500, in `ink`, not muted, so it reads at a glance. Sentence case, above the field, never inside it. An optional field says "optional" in muted after the label; required is the default and carries no asterisk.
- Field: `radius-md`, `surface`, 1px `line` border, the full width of the card's content edge. 36, 40 or 44px tall by density, text inset `space-3`, `space-3`, `space-4`. The value is `body` 14px in `ink`; `kind: identifier` sets it in JetBrains Mono at 14px, because what must match exactly reads in the face that shows every character. The placeholder stays sans.
- Placeholder: `muted`, 5.90:1 on surface. It is an example, never the label.
- Message slot: one line under the field in sans 12.5px/1.4, weight 400, because helpers and errors are sentences. `space-1` below the field at compact and `space-2` otherwise. The helper is `muted`, for example "Any public repo, as owner/name or a github.com link". A fact that follows the sentence, such as "GitHub returned 502", stays in mono at the `meta` size. The error, checking and unreachable lines take the same slot, so nothing below shifts. Its 10px mark sits on the first line.
- Hover: the border deepens to `line-strong` (proposed token, ink at 22%). No shadow, no lift.
- Focus: a 2px `focus` ring (13.04:1 on surface) at 2px offset, outside the field's own 1px border, and a caret in `accent`. The border never changes on focus, so an invalid field with focus shows both: the crit border inside, the focus ring outside, surface between them. Never accent, never a glow.
- Error, the input is wrong and blocks submit: `crit-fill` border (6.62:1), filled crit mark, the sentence in `crit` (7.49:1), for example "That repo is private or doesn't exist" or "That isn't a GitHub repo · try owner/name".
- Unreachable, GitHub failed and the reader did not: the border stays `line`, unavailable mark, "Couldn't check this repo" in ink, the cause as a mono fact ("GitHub returned 502"), Try again in `accent-text` (5.38:1) at the end of the line. Never crit: crit is for what blocks, and a failed request is never red.
- Checking: the value stays put and readable (`readonly`, `aria-busy`); the warming mark and "Checking vercel/next.js on GitHub" in muted fill the slot.
- Disabled: `bg` ground, `line-soft` border, label, value and chevron in muted (5.67:1 on bg). The helper always says why, for example "Fixed by this screen · start over to change it".
- Hero: 52px, `radius-lg`, `surface` on `bg` with the `card` shadow. A 44px primary button sits inside at `space-1`, so the corners nest (14 + 4 = 18). Placeholder 16px sans, value 16px mono at every viewport, so iOS never zooms, text inset `space-4`, message slot `space-3` below on the text edge. One size at every density. Disabled only when the daily cap is reached, and then the slot says so and points at the sample repos.
- Skeleton, empty and warming do not apply: a field has nothing to load and renders at once. Checking is the field's own wait.
- Motion: the field arrives with its card and has no move of its own. The message slot rewrites with a wipe at feedback speed: the old line wipes out left to right as the new one wipes in, 350ms, `power3.inOut`. Border color changes in 120ms. The focus ring appears at once. Nothing bounces. Reduced motion swaps the slot with a 200ms opacity change.
- Accessibility: a real `<label for>`, the message slot in `aria-describedby`, `aria-invalid` on error, and focus moves to the first invalid field on submit. The slot is a polite live region while checking. Identifier fields set `spellcheck="false"`, `autocapitalize="none"` and `autocomplete="off"`; the hero adds `inputmode="url"` and a visually hidden label ("Public GitHub repository"). Below 480px viewport width the field's text (value and placeholder) goes to 16px through a media query, because iOS Safari zooms into any field under 16px; desktop sizes stay as drawn. The resting border is 1.22:1 by design, with the label and placeholder carrying identity; under `prefers-contrast: more` it switches to `muted` (5.90:1).
